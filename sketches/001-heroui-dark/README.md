## Variant: HeroUI / Next UI — Dark & Modern

### Design stance
**Bold, modern, immersive** — un style sombre avec des dégradés, du verre (glassmorphism), et des couleurs vives. Inspiré de HeroUI (ex-Next UI) et des tendances dark mode premium.

### Key choices
- **Layout** : Sidebar fixe à gauche + contenu scrollable à droite
- **Thème** : Dark mode total (#0a0a0f), badges colorés, gradients
- **Cartes** : Glassmorphism (fond translucide + bordure fine + blur)
- **Boutons** : Arrondis (12px), gradients, ombres portées lumineuses
- **Typographie** : Inter, tailles généreuses, tracking précis
- **Interactions** : Hovers subtils (blanc 2-6%), transitions fluides

### Trade-offs
- **Fort** : Look premium, moderne, immersif. Les données "ressortent" visuellement
- **Faible** : Moins professionnel "corporate". Consomme plus d'encre en impression. Le glassmorphism peut être lourd si trop d'éléments

### Best for
- Une app moderne qu'on veut faire "waouh" aux utilisateurs
- Public jeune (coachs, joueurs U15-U17) qui attend une app "comme les apps du téléphone"
